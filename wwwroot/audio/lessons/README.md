# Lesson audio

Recordings are optional. Every listening activity uses the browser's Japanese system voice when no MP3 is present. Add recordings using the paths shown on **Admin Panel → Audio Coverage** only if you later want to upgrade audio quality.

Convention:

`{lessonId}/activity-{activityId}-slow.mp3`

`{lessonId}/activity-{activityId}-natural.mp3`

Both files should contain the same Japanese text. The slow recording is intended for learners; the natural recording should preserve normal Japanese rhythm. If a file is absent, the lesson page keeps its system-voice fallback.
